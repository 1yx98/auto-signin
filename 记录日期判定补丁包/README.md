# 记录日期判定补丁包 —— 可插拔修复 D

> 建于 2026-09-17。修的是「**今天明明已签到，却被误报成 not_time**」。

## 这个包修的是什么

**原代码**（`click_sign_button` 内的"第二道时间守卫"）：

```python
if finish_clicks == 0 and not _within_signin_window():
    logger.warning("...该记录必然不是今天的，判 not_time"
                   "（防止把昨天'已结束'记录误判成今天已签）")
    return "not_time"
```

**设计意图是对的**（防止把昨天的记录当成今天的成功 = 假成功），
**但它的前提不成立**：

> 「不在签到时段内的灰色'已签到'记录**必然不是今天的**」

**2026-09-17 实测反例**（`run_20260917_215517`）：
用户在 **21:25 自己手动签了**（重复签到场景），脚本 **21:57** 才跑。
详情页截图显示：

```
每日签到
• 2026.09.17 20:50 至 2026.09.17 22:00
签到记录：签到时间 2026-09-17 21:25   签到校区：鄠邑校区
按钮：灰色「已签到」
```

**那条记录就是今天的**，却被判成 `not_time`。

**后果**：台账把"今天已签到"记成 `not_time` —— 统计失真、用户以为没签上。

**根因**：这个守卫只考虑了"**脚本自己签**"，没考虑
"**用户自己在时段内手动签了**"（本项目已知的"重复签到"场景）。
它用**时间**反推，而页面上有**更直接的证据：日期**。

> 项目 README 早已记下这条：
> 「详情页同时显示日期 —— **日期是比按钮更直接的证据**，未来若要彻底根治可考虑读日期。」

## 怎么修

| id | 做什么 |
|---|---|
| D1 | 注入 `_detail_record_is_today()` —— OCR 整窗，取「签到时间」之后的 8 位数字（YYYYMMDD），与今天比较 |
| D2 | 那个守卫加一个条件：**页面日期就是今天 → 不判 not_time**（直接算成功） |

**★ 真实样本已验证可读**（不是合成样本）：

```
OCR 原图输出：'...签到记录签到时间：2026·09·1721：25签到校区：鄂邑校区'
→ 取「签到时间」后 8 位数字 = 20260917 == 今天 ✅
```

**★ 安全设计**：**读不到 / 引擎不可用 / 异常 → 返回 False**
（铁律 R7：读不到 ≠ 坏的）。返回 False 时，**行为逐字等价于改动前** ——
即仍然按原来的时间窗守卫处理，不会因为"读不出日期"而放松对假成功的防范。

**注意方向**：本包**不会**放宽对"昨天记录"的防范 ——
只有**明确读到今天是今天**时才改变判定。读不到就退化为原逻辑。

## 已知边界

- OCR 读日期**依赖页面渲染**。若页面未渲染完 / 字体异常 / 窗口被遮挡，
  可能读不到 → 此时返回 False，**退化为原逻辑**（不会误判成"今天"）。
- 只认「签到时间」这个锚点。若小程序改版把这行文字改了，读不到 → 同样退化。
  **属于"该更新补丁定义"的情况，不是 bug。**

## ★★ 2026-09-18 修正：`_detail_record_is_today()` 原来**整屏 OCR**（真 bug）

**用真实样本离线验证时发现的**：

```
同一张真实样本（logs/run_20260917_215517/215706_详情页_时段外已签_疑历史记录.jpg）：
  · 整屏 OCR   -> 「签到时间」后的数字读成 520260972125（多出一位 5）-> 日期取错
  · 裁窗口 OCR -> 202609172125 -> 20260917  ✅
```

**根因**：`full` 是**整屏截图**，直接整屏 OCR 会把任务栏 / 资源管理器 /
其它窗口的文字一起读进来，干扰了「签到时间」那一行。

**修法**：先用 `win_rect(hwnd)` 裁出小程序窗口那一块，再 OCR：
```python
_wl, _wt, _wr, _wb = win_rect(hwnd)
...
_win = full[_wt:_wb, _wl:_wr]
_txt = (_ocr_read(_eng, _win) or "").replace(" ", "")
```

**修后验证**（真实样本）：能正确读出 `20260917` 并按日期判定 ✅
