# 油学通 自动签到（微信 PC 端）

由 **i西邮 自动签到** 项目迁移改造而来，目标从「西安邮电大学 i西邮」换成「西安石油大学 油学通」小程序。

每天定时自动打开微信 → 搜索并进入「油学通」小程序 → 顺着「日常管理 → 签到消息 → 每日签到 → 进入按钮」多级入口进到签到详情页（详情页"签到" → 地图定位页"完成签到" → 硬确认"已签到"）→ 成功后自动关机。

> ⚠️ **迁移后到手必做 3 件事（不做跑不起来）**：
> 1. 双击 `1_采集模板.bat`，重新采集 **油学通专属的 5 个模板**：搜索结果里的「油学通小程序图标」、工作台「日常管理」入口、「签到消息」入口、「每日签到」入口、点「每日签到」后进入签到页的那个「进入按钮」（原来的 i西邮 图标已删除，无法复用）。另有 2 个微信通用模板（进入微信确认键 / 搜索框），界面没变可输 s 跳过。
> 2. 签到时间已按 鄠邑校区「20:50 开始签到」设好，定时触发 20:55；如需调整，改 `config.json` 的 `signin_time_start`/`signin_time_end`，并同步改 `install_task.ps1` 的 `$triggerTime`。
> 3. 双击 `2_手动测试签到(管理员).bat` 完整跑一遍，确认能进详情页、能定位、能走到"已签到"。

## 一、它是怎么工作的（signin.py）

1. **清障**：自动识别并关闭抢占前台的「屏幕外幽灵弹窗」（典型如联想电脑管家 lxwp 的高权限弹窗，会导致所有模拟点击落空）。需要脚本以管理员权限运行才能结束这类高权限进程。
2. **启动/唤醒微信**：没开就启动；最小化了会自动还原；停在「进入微信」确认页就自动点进去。进入后**等待界面真正渲染完成**（微信 4.x 启动时可能整块白屏，脚本会检测白屏并自动重绘/重启微信，绝不拿白屏去操作）。更新说明弹窗只在**同时识别到弹窗标题**时才点其右上角 X，避免误点微信主窗自身的关闭钮。
3. **搜索小程序**：用图像模板精准定位顶部搜索框（不写死坐标，微信窗口大小不同都能点中）→ 粘贴「油学通」→ 在「最近使用过的小程序」里用**多尺度图像匹配**找到 油学通 图标并点击。打开前会先清掉残留的旧小程序进程，保证每次从工作台首页进入（不会恢复到上次的详情页）。**全程绝不按 Esc**——实测微信 4.x 按一次 Esc 主界面就会整块白屏且无法自恢复。
4. **逐级进入签到详情页**：按 config 的 `signin_nav_steps` 顺序一路点进去——工作台「日常管理」→「签到消息」→「每日签到」→「每日签到里的进入按钮」→ 签到详情页（每一步都是首屏找不到就小步向下滚动；图标由各自模板定位，务必按油学通实际界面重新采集）。
5. 多级入口的最后一步「进入按钮」点进去后就到**签到详情页**（左边蓝色"签到"、右边绿色"请假"），无需中间的任务卡片点击。
6. **签到（两步页面）**：
   - **详情页**：只在窗口下半部动态扫描宽幅按钮，自动排除顶部蓝色标题栏——蓝色「签到」=可签（绿色「请假」不会误点）；灰色「已结束」=不在时段或已签，不点击、不关机。
   - **地图定位页**：点蓝色签到后进入地图页，等定位完成、底部「完成签到」由灰变**绿**后点击；若弹出「签到成功,是否返回?」自动点「确定」。
7. **关机**：判定签到成功后，按 `config.json` 的 `shutdown_delay`（默认 60 秒）倒计时关机。

> 全程不写死像素坐标：搜索图标用多尺度模板匹配、签到按钮按颜色和形状动态扫描，微信窗口大小不同也能识别。
>
> **日志按运行次数归档**：每次运行在 `logs/run_年月日_时分秒/` 里单独存一份 `run.log` 和该次全部过程截图，自动保留最近 30 次（`config.json` 的 `keep_runs` 可调）；`logs/signin_当天.log` 是当天所有运行的汇总，定时任务另写 `logs/task_run.log`。排查问题时直接看最新的 `run_*` 文件夹即可。

## 二、首次安装（只需做一次）

双击运行 **`3_安装定时任务(管理员).bat`**，在弹出的 UAC 窗口点「是」。
它会创建/更新名为 **「油学通每日签到」** 的 Windows 定时任务：

- 每天 **20:55** 自动运行（`install_task.ps1` 的 `$triggerTime`；鄠邑校区 20:50 开始签到，留 5 分钟余量）
- **以最高权限运行**（这样才能自动清理联想电脑管家等高权限弹窗，且任务计划触发时不会再弹 UAC）
- 仅在你登录时运行、唤醒计算机执行、用电池也运行、错过时间会补跑、最长运行 30 分钟

> 前提：到点电脑处于开机且微信已登录（你已确认满足）。电脑睡眠也没关系，任务设置了唤醒。

## 三、手动测试

- **`2_手动测试签到(管理员).bat`**：推荐。自带提权（弹一次 UAC，点「是」），和夜里自动运行环境完全一致。
- **`2_手动测试签到.bat`**：不提权版本，当前台没有高权限弹窗时也能用。

**怎么看结果**（黑窗口最后一行「退出码」）：

| 退出码 | 含义 |
|---|---|
| 0 | 签到成功，已执行关机倒计时 |
| 3 | 不在签到时段 / 今日已签到（**非签到时段测试时看到 3 属正常**，说明前面链路都走通了，只是按钮是灰的）|
| 1 / 2 | 失败 / 异常，去 `logs/` 看日志和截图 |

想完整验证「真签到 + 关机」，在签到开放时间之后运行测试 bat 即可。

## 四、配置（config.json）

| 字段 | 说明 |
|---|---|
| `search_keyword` | 搜索关键词，默认 `油学通` |
| `miniprogram_title` | 小程序独立窗口标题（用于窗口查找/置顶），默认 `油学通` |
| `miniprogram_search_icon` | 搜索结果里「油学通」图标模板路径，默认 `templates/02_miniprogram_icon.png` |
| `signin_nav_steps` | 多级入口顺序（数组）：日常管理→签到消息→每日签到→每日签到里的进入按钮，每项含 name/template/scroll，默认 21/22/23/24 四张模板 |
| `signin_time_start` / `signin_time_end` | 签到开放/结束时间（仅提示用，不硬卡），默认 `20:50` / `21:30` |
| `confidence` | 通用图像匹配置信度，默认 0.8 |
| `shutdown_after_success` | 成功后是否关机，默认 `true`（想只签到不关机改成 `false`）|
| `shutdown_delay` | 成功后多少秒关机，默认 60 |
| `keep_runs` | 自动保留最近多少次运行日志/截图，默认 30 |
| `log_dir` | 日志/截图目录 |

## 六、常见问题

- **没反应 / 日志显示前台被抢占**：联想电脑管家等会在屏幕外弹出高权限模态窗。务必用「管理员」版本运行，或重新运行 `3_安装定时任务(管理员).bat` 保证任务是最高权限。
- **微信窗口大小变了会不会失效**：不会，搜索用多尺度匹配、按钮动态扫描；但请不要在脚本运行时手动拖动/缩放微信窗口。
- **微信白屏（界面整块纯白）**：微信 4.x 的已知毛病，按 Esc、窗口快速切换都可能诱发。脚本已内置白屏检测，会先等渲染、再最小化/还原强制重绘，仍不行就自动重启微信；同时脚本自身已彻底不按 Esc。若手动操作时遇到白屏，关掉微信重新打开即可。
- **模板失效（微信或油学通改版后）**：运行 `1_采集模板.bat` 按提示重新截图（尤其 02/21/22/23/24 这 5 个油学通专属模板）。
- **按钮识别与"成功硬确认"（8/31 修复，9/1 增强）**：① 只认"纯色填充率≥0.6 且不横跨贴满窗口两边"的按钮——窗口圆角外透出的桌面壁纸颜色可能被误连成大块，已据此剔除；② 严格两页状态机：蓝色"签到"在=详情页（旁边绿色是"请假"绝不点），蓝色消失后出现的绿色才是地图页"完成签到"，且只点一次；**成功必须有界面依据**——点到绿色只代表请求发出，之后会反复点详情页"基本信息"右侧的刷新按钮(↻)重新向服务器拉取状态，连续 2 次见到灰色"已签到"宽按钮（此时蓝签到、绿请假都消失）才判成功，并截图存档 `签到成功_已签到`；**单轮约 50 秒刷不出"已签到"，会冷启动小程序、把"搜索→进入→签到→确认"整套流程完整重走一遍（最多两轮，间隔 8 秒）**；只有两轮都确认不到才判**失败、不关机、保留现场**（`FAIL_未确认签到成功`）。注意区分：地图页"不在区域内"灰按钮在窗口约 0.83 高度，已签详情页灰按钮在约 0.72 高度，不会互相误判；③ 已关闭 PyAutoGUI 的鼠标四角紧急中止（FAILSAFE）。
- **地图页灰色"不在区域内"/定位漂移（9/1 晚修复）**：电脑没有 GPS，靠"周边 WiFi 热点位置库 + IP"定位，偶尔会把身边热点错定位到校外，此时绿色"完成签到"不出现、按钮是浅灰色。脚本会自动两级自愈：先每 6 秒点一次地图右下角"重新定位"；连续 3 次仍无绿色，就自动断开重连当前 WiFi，强制系统重新扫描热点、重算定位，WiFi 只重连一次，地图页总等待约 78 秒。注意：① 这只解决"人确实在校区、但 PC 定位漂移"，人不在校区无法签到；② 签到时让 Clash/VPN/加速器处于"关闭系统代理、未开 TUN"状态——任务管理器里残留 `clash-verge-service` 空壳服务并不影响，但一旦真开了系统代理或 TUN，IP 定位会跟着节点走而漂移；③ 若自愈仍失败，可手动断开重连 WiFi、改连校区网络，或直接用手机签到。
- **Python 运行时（已独立，不依赖豆包）**：项目内 `runtime\` 是一份完整独立的绿色 Python 3.13（含全部依赖，约 282MB），各 bat 用相对路径 `%~dp0runtime\python.exe` 调用。因此豆包更新/卸载都不影响签到，整个 `youshengtong_signin` 文件夹拷到别的同架构 Windows 电脑也能直接用，无需另装 Python。**请勿删除 `runtime` 文件夹**；若确要重建，把任意一份装好 pyautogui/opencv-python/numpy/pyperclip/Pillow 的 Python 目录整体复制为 `runtime\`（保证 `runtime\python.exe` 存在）即可。
- **想改签到时间**：改 `install_task.ps1` 里 `$triggerTime` 后，用 `3_安装定时任务(管理员).bat` 重装；时间必须晚于签到开放、早于结束，否则按钮是灰的签不上。同时把 `config.json` 的 `signin_time_start`/`signin_time_end` 改成一致。
- **平时可以把微信完全退出吗**：可以。脚本到点会自己启动微信，只要微信保持「已登录」状态即可（退出的是程序进程没问题；不要「退出登录」）。最小化到任务栏也没问题，脚本会自动还原；即使主窗被收到系统托盘，脚本也会再次启动微信把单实例主界面唤出来。
- **无人值守必须保证：不锁屏、不睡死、网络通**（脚本已尽量自动处理，但有几点需要系统设置配合）：
  - 脚本运行期间会自动调用 `SetThreadExecutionState` **阻止系统睡眠/熄屏**，进程结束自动还原；定时任务本身也勾选了"唤醒计算机运行"。
  - 但**自动锁屏脚本无法替你解锁**（也不应保存密码）：请在「设置→账户→登录选项」把"离开后要求登录"放宽，或在「电源和睡眠」里把睡眠时间设为"从不"，确保到点时停在**已登录的桌面**而不是锁屏。脚本检测到锁屏会直接判失败并记录 `FAIL_屏幕锁定`。
  - **笔记本务必接通电源**，并在「控制面板→电源选项→选择关闭笔记本盖功能」把合盖设为"不采取任何操作"（或干脆不合盖）。脚本开跑会记录是否接通电源/电量。
  - 夜里保持 WiFi 已连接且能正常上网；签到时让 Clash/VPN/加速器处于"关系统代理、未开 TUN"状态。
- **脚本内置的自动预防/自愈（按执行顺序）**：① 开跑先清掉联想电脑管家等"屏幕外幽灵弹窗"、阻止睡眠、检测锁屏、记录环境快照；② 微信白屏→等待→最小化还原重绘→仍白屏就杀进程重启；更新弹窗需先认到标题才点 X；③ 搜索进小程序自带 4 次重试、每轮都冷启动小程序避免停在旧子页；④ 定位漂移→点地图"重新定位"→仍不行自动重连当前 WiFi 并验证公网真的可达；⑤ 点完成签到后反复刷新详情页、连续 2 次见到灰色"已签到"才算成功；⑥ 单轮失败自动整套重走第二遍，两轮都失败才判失败、不关机并保留截图；⑦ 只有确认成功才在 60 秒后关机（期间可 `shutdown /a` 取消）。
- **失败了怎么排查（run.log 怎么读）**：每次运行独立存放在 `logs/run_年月日_时分秒/`，其中 `run.log`（UTF-8）结构固定，从上到下：运行环境信息 → 环境快照 → 全程 `[里程碑]` → `[扫描]` 调试行 → 结尾"运行总结"。同目录还有每步过程截图，`FAIL_*.png` 就是失败现场；脚本判失败时一定不会关机，方便当场查看或用手机补签。

## 七、复制到别的电脑（迁移）

整个 `youshengtong_signin` 文件夹（**必须含 `runtime\`，约 214MB**）原样拷过去即可，Python 和依赖不用重装、bat 用相对路径也不用改。新电脑满足以下条件：

1. **64 位 Windows**（runtime 是 AMD64；ARM/32 位不行）。
2. **装好 PC 微信并保持已登录**，且你能在这台电脑上手动打开「油学通」完成签到。微信装在任意盘/目录都行，脚本会自动探测 `Weixin.exe/WeChat.exe`；万一探测不到，把实际路径填进 `config.json` 的 `wechat_path`。
3. **人/电脑在校区定位范围内**：签到靠地图定位到校区，不在校区会定位失败，这与脚本无关。
4. 文件夹放任意路径均可（桌面、D 盘都行）。
5. 先双击 **`1_采集模板.bat`** 重新采集油学通模板；再双击 **`2_手动测试签到(管理员).bat`** 完整跑一遍确认；最后双击 **`3_安装定时任务(管理员).bat`** 在新机注册定时任务（Windows 定时任务不会随文件夹复制，必须在新机重装一次）。

> 分辨率/缩放：脚本已设置 DPI 物理像素感知、模板多尺度匹配、按钮按颜色形状动态扫描，常规 1080P/2K 屏一般可直接用。若新机日志出现"模板匹配超时"，在新机运行一次 `1_采集模板.bat` 重新采集模板即可。
